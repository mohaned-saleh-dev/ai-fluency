1. Introduction

1.1 Purpose

This SRS defines the software requirements for Tamara’s AiQ Fluency Assessment — an enterprise platform to define, assess, measure, and develop AI fluency across Tamara’s workforce using a structured conversational assessment aligned to the AiQ Framework (6 dimensions, role-specific weighting, 0–100 composite score, 4 maturity bands).

The document bridges the strategic framework (Executive Summary PDF v1.2), the working prototype (aiq_csuite), and competitive UX patterns (AISA) adapted to Tamara’s brand, regulated context, and internal use case.

1.2 Scope

In scope: Self-serve conversational AiQ assessment (~10 minutes); role × seniority calibration; evidence-based scoring and participant-facing coaching report; admin session review and telemetry; org-level fluency dashboards (later); executive framework deck; pilot for internal reflection & L&D with path to hiring and performance integration.

Out of scope for initial releases: See Section 19.

2. Overall description

2.1 Product perspective

Tamara AiQ is a measurement + development system, not a certification marketplace. It sits as a competency layer across: Hiring (AiQ Challenge) → Onboarding → Quarterly refresh → Performance/L&D → Workforce planning. The pilot focuses on current employees, self-assessment, reflection & coaching, with admin visibility.

2.2 Product principles

  1. Conversational, not multiple-choice — measures demonstrated behavior.
  2. Augmentation, not automation — rewards extending human expertise with AI.
  3. Role-fair — same rubric, different weights and scenario emphasis.
  4. Evidence-backed — every dimension score traceable to transcript quotes.
  5. Regulated-context aware — D6 is a floor for everyone; deeper for risk/legal/finance.
  6. Tamara-native — brand, tone, fintech governance embedded.
  7. Short enough for executives — target ~10 minutes; max ~6 user turns in scenario mode.
  8. Transparent to participants — respectful second-person copy.

7.4 Interview depth (“6 + 2”)

Light pass across all six dimensions; deeper follow-up on the two highest-weighted dimensions for the participant’s level × job family. Pilot framing: reflection and coaching, not hiring rank.

8. User journey requirements

Target flow: Landing → Onboarding (5 steps) → Chat → Scoring wait → Report slides (5) → PDF → Playbook.

8.1 Landing (P0–P1)

Explain conversational ~10 min assessment; Tamara branding; CTA “Begin assessment”; optional badges (6 dimensions, 0 multiple choice, role-weighted).

8.2 Onboarding wizard (P1)

StepContent
1Ready for a chat — duration, deliverables
2Benchmark preview / sample chart
3Intent: what brings you here (6 options)
4Level + job family
5Expectations + privacy note

8.3 Chat (P0–P1)

Phase/dimension banners; timer; progress pill; composer; “View results”; mobile-responsive (min 320px).

8.4 Scoring interstitial (P1)

“Reviewing your conversation for evidence…”; ETA; progress bar; optional links while waiting.

8.5 Report reveal — 5 slides (P1)

  1. Your results are ready
  2. Composite score + persona (+ percentile if cohort exists)
  3. 6-dimension chart with weights
  4. Top gaps + evidence quotes + next steps
  5. Learning plan + PDF download

9. Reporting and coaching

Participant report SHALL include: AiQ 0–100; maturity band; 6 dimension scores with rationales; strength + risk lines; top gaps vs target; per-dimension actions; up to 4 learning links; pilot disclaimer.

SHOULD include (R2): Persona; evidence quotes; neutral integrity note if flagged.

Org reporting (R3): AiQ Index; dimension averages; band distribution; team filters; QoQ trend; CSV export.

Colors: Lavender #9600F1, Purple #5300BA. Font: Plus Jakarta Sans. Logo: tamara wordmark on purple/lavender; no brightness filter on PNG.

UX patterns to adopt (Tamara-styled): Multi-step onboarding; in-chat progress pill; scoring wait; 5-slide report; internal cohort percentile chart (n ≥ 30). Do not copy AISA dark/neon as primary identity.

17. Phased delivery plan

R1 — Pilot MVP (4–6 weeks)

  • Stabilize core flow, scoring retry, session resume
  • Finalize weights vs executive deck
  • Evidence quotes in scoring JSON + report
  • Postgres prod, VPN deploy, admin training
  • Legal disclaimer and retention policy

Exit: 50 employees complete; L&D sign-off on rubric tone.

R2 — Enhanced experience (6–8 weeks)

  • 5-step onboarding wizard
  • 5-slide report reveal + PDF
  • 8 personas; scoring interstitial
  • 12 sub-criteria in rubric; AiQ Playbook (30 articles)
  • DOL + Anthropic alignment appendix

R3 — Workforce intelligence (8–10 weeks)

  • Org dashboard (AiQ Index, histograms, team filters)
  • Dual-track + calibration scoring
  • Manager assessment mode; enhanced integrity

R4 — Enterprise (ongoing)

SSO, HRIS, AiQ Challenge (30–45 min exercise), ATS, quarterly campaigns, Arabic.

18. Acceptance criteria

R1

  • End-to-end completion without admin help
  • Report: AiQ, 6 dimensions, band, 3+ coaching actions
  • PDF download works
  • Admin views transcript + telemetry
  • Session survives browser refresh
  • Scoring success ≥ 95%

19. Out of scope

  4. Webcam proctoring
  5. Custom fine-tuned Tamara LLM (v1)
  6. Native mobile apps
  7. Copilot tenant usage analytics (separate project)
  8. Performance management process implementation
  9. New dependencies without security review
